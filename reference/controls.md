# Confirmed original mechanics and input sources

The supplied EXEs remain the primary reference. These dated contemporary
descriptions resolve controls that are hard to infer from a still image. They
describe the named PC games, not the later mobile HD versions.

| Game | Confirmed behavior | Source |
| --- | --- | --- |
| 一気ノミ (`ikki`) | Repeated mouse clicks drink milk. Clicking too fast makes Kutar spit it out. Time to empty the bottle is the goal. | [Vector's original software listing](https://www.vector.co.jp/soft/win95/game/se133185.html), [Vector's 2000 review](https://www.vector.co.jp/magazine/softnews/000401/n000401com1.html) |
| リフト (`lift`) | One mouse click seats Kutar when the moving lift reaches him; score counts consecutive riders. | [2000 review](https://forest.watch.impress.co.jp/article/2000/03/13/kutarnolift.html) |
| ヒップダンス (`HipDance`) | Left/right mouse buttons raise the corresponding hand. Copy the sequence demonstrated by the other dancers in rhythm. | [2000 review](https://forest.watch.impress.co.jp/article/2000/08/28/kutarnohipdance.html) |
| ハーベスト (`hvst`) | Hold left/right mouse button to move the harvester left/right while avoiding obstacles. | [2002 review](https://forest.watch.impress.co.jp/article/2002/09/17/kutarharvest.html) |
| チャンバラ (`chan`) | Left click swings left, right click swings right. Hitting an enemy scores; missing or touching one ends the game. | [2003 review](https://forest.watch.impress.co.jp/article/2003/03/18/chanbara.html) |

Other games' exact input, score thresholds and timing still need direct checks.
The UI now maps a directional touch or button to the corresponding original
mouse button. The generic control category does not by itself verify each
game's rules.
